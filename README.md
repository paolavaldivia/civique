# Civique 🇫🇷

Une plateforme moderne, gratuite et open source pour préparer le test d'évaluation du français et des valeurs de la République française.

## ✨ Fonctionnalités

- **🎴 Mode Flashcards** : Apprenez avec des cartes mémo et l'algorithme de répétition espacée (SM-2) pour une mémorisation optimale
- **📝 Mode QCM** : Entraînez-vous avec des questions à choix multiples comme au vrai examen
- **📚 Mode Étude** : Parcourez le contenu par thématique pour approfondir vos connaissances
- **📊 Suivi de progression** : Votre progression est sauvegardée localement dans votre navigateur
- **🎨 Interface moderne** : Design épuré avec animations fluides

## 🚀 Technologies

- [TanStack Start](https://tanstack.com/start) - Framework full-stack React
- [TypeScript](https://www.typescriptlang.org/) - Typage statique
- [Tailwind CSS](https://tailwindcss.com/) - Styling utilitaire
- [Framer Motion](https://www.framer.com/motion/) - Animations
- [Zustand](https://zustand-demo.pmnd.rs/) - Gestion d'état

## 📚 Thématiques couvertes

1. ⚖️ **Principes et valeurs** - Les valeurs de la République française
2. 🏛️ **Institutions** - Le fonctionnement des institutions
3. 🇫🇷 **Symboles** - Les symboles de la République
4. 📚 **Histoire** - L'histoire de France et de la République
5. 🗺️ **Géographie** - La géographie française
6. 🎨 **Culture** - La culture française
7. 🏠 **Vie quotidienne** - La vie en France au quotidien

## 🛠️ Installation

```bash
# Cloner le repository
git clone https://github.com/paolavaldivia/civique.git
cd civique

# Installer les dépendances
npm install

# Lancer le serveur de développement
npm run dev
```

L'application sera accessible sur `http://localhost:3000`

## 📦 Build

```bash
# Créer un build de production
npm run build

# Lancer le serveur de production
npm start
```
